# Stage 3: Register Foundational Docs

Identify the smallest useful set of foundational project sources.

## Starter Source Types

- README or project overview;
- product, strategy, or operating docs;
- architecture or process docs;
- decision records;
- current roadmap or planning docs;
- glossary, domain model, or terminology notes;
- external references explicitly supplied by the user.

## Rules

- Prefer canonical, current docs over drafts and generated notes.
- Keep working notes and generated context in lower authority layers.
- Capture enough metadata to register each source later:
  - title;
  - path or URL;
  - owner or origin if known;
  - last modified date if available;
  - authority layer;
  - relevant wiki questions it answers.
- Do not deeply summarize every document in this stage; capture only what is needed to seed the wiki.

## Continue When

You have a bounded list of foundational sources and know which one becomes the first source summary.
