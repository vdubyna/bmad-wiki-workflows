# Stage 5: Review And Source Backlog

Close with a review gate and a small source-registration plan.

## Present

Summarize:

- files created or updated;
- source locations inspected;
- authority layers;
- assumptions;
- open questions;
- recommended next sources to register.

## Ask

Ask only the next decision needed:

- Is the project profile acceptable as `draft`?
- Which source should be registered next?
- Are there extra privacy exclusions before registering more sources?

## Do Not

- Do not commit without explicit approval.
- Do not mark pages `approved` without user review.
- Do not start broad source registration unless the user asks for it.
