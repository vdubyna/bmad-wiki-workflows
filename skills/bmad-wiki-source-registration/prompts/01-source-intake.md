# Stage 1: Source Intake

Establish what source is being registered and why it belongs in the wiki.

## Steps

1. Check the current wiki repo status with `git status --short`.
2. Identify the source only from the user message or explicit saved workflow context.
3. Capture:
   - source title or working name;
   - source path, URL, export, or system reference;
   - source type;
   - owner/origin if known;
   - intended wiki use;
   - access permission;
   - privacy exclusions;
   - whether this is new, changed, or replacing an older source.
4. If the source is missing or access is unclear, stop and ask for the missing details.

## Continue When

You can state the source identity, type, access status, intended wiki use, and privacy boundaries.
